# Template

よく使う文章(メール定型文、返信テンプレなど)を保存しておいて、ボタン一つでクリップボードにコピーできるシンプルなWebアプリです。

**公開URL:** https://template-gallery-tan.vercel.app

## 使い方

1. 「+ 新規テンプレート」からタイトル・カテゴリ・本文を入力して保存
2. カードの「コピー」ボタンでクリップボードにコピー
3. 検索欄・カテゴリ絞り込みでテンプレートを探せる
   - テンプレート自体の削除は、誤タップ防止のためカードではなく「編集」ダイアログの左下にある
4. 【分岐】〔入力欄〕を使うカードでは、入力した内容を「＋ この内容を保存」で一時保存できる。保存した内容は各行の「コピー」でワンタップコピー、「編集」で呼び出して続きを書ける、「削除」でその1件を消せる。「選択」を押すとチェックボックスが出て、複数まとめて削除（1件だけ選べば編集・名前の変更）ができる
5. 「書き出し」でJSONファイルとしてバックアップ、「読み込み」で復元・他端末への移行

データはブラウザの localStorage に保存されます(その端末・ブラウザ内のみ)。バックエンド不要の静的サイトです。

## ローカルで確認する場合

```
python3 -m http.server 8000
```

`http://localhost:8000` を開いてください。
